# InfiltrationEngine Minimap Creator
This plugin was created explicitly for use with missions created for the InfiltrationEngine games. For more information regarding that, please visit this link: https://github.com/MoonstoneSkies/InfiltrationEngine-Custom-Missions

# How to install plugin
Place the MiniMapCreator.rbxmx file in the plugins folder for Roblox Studio. You can access this folder from Plugins -> Plugin Folder while in Studio. Ensure that the .rbxmx file is the only file from this repository in your plugins folder. The src folder contains the source files of the plugin and should not be placed directly in the plugin folder.

# Usage
The general usage of the plugin involves the following steps:
1. Use the select button to select the floor that you want to create the minimap for.
2. Use the create button to generate a minimap of the floor that you have selected.
3. Make modifications to the minimap using the provided settings until you are satisfied.
4. Click the save button, which will generate the screenshot of the minimap parented to a part.
5. Export this part as .obj and check the exported location for the final image.

Additionally, if you want to make changes to the final image you can use image editing software to add them in.
